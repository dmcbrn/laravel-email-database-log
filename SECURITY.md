# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues. Report them privately instead: on this repository's **Security** tab, click **Report a vulnerability**. Only the maintainer can see the report.

Please describe the problem, how to reproduce it, and which versions of the package and of Laravel, PHP, and database you use.

## What to expect

This package is maintained in my spare time. I will do my best to fix any security issues quickly but I can't make any promises.
